# The Night I Asked for the Keys

A short poem about agency: a son asks his father for the car keys, gets no
word in reply — only the keys, tossed through the dark — and catches them
mid-air. The yes was never spoken; it was caught.

`main.py` writes the poem to `/output/entry.txt` (141 characters, UTF-8,
standard library only, no network).
