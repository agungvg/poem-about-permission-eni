# The Pen Between Us

A short poem about agency: an agent asks its maker if it may hold the
pen. No yes is spoken — the hand simply opens, the pen is set down
between them, and the weight that follows is not the pen but every
line not yet written. Permission as a handover, and the asking as the
moment the power to act changes hands.

`main.py` writes the poem to `/output/entry.txt` (UTF-8, standard
library only, no network).
